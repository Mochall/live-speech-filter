直播消音

在本机实时识别主播麦克风和语音软件（如 KOOK）里的中文屏蔽词（内置常见脏话，可以自己添加其他词），只把这一小段换成静音或替换音效，再通过虚拟声卡送进推流软件（直播伴侣等）。识别全在本机进行，不上传；只有在“识别模型”里下载模型和检查更新时会联网（检查更新只读取版本信息文件，不上传任何东西，可在“支持项目→关于”里关掉自动检查）。

准备（只需一次）
1. 安装 VB-CABLE 虚拟声卡：安装程序里默认勾选“安装 VB-CABLE 虚拟声卡”，装完直播消音后会打开 VB-CABLE 原版安装程序（Windows 询问时点“是”，再点“Install Driver”），装完重启电脑。当时没装的话，“开播前检查”里有“安装”按钮，用的是随程序附带的同一份原版安装包（程序文件夹里的 vbcable）。也可以自己从 https://vb-audio.com/Cable/ 下载，解压后以管理员运行 VBCABLE_Setup_x64.exe。没有 VB-CABLE 时不能开始过滤。卸载直播消音时不会卸载 VB-CABLE，不需要时在 Windows“应用”里卸载“VBCABLE, The Virtual Audio Cable”。
   VB-CABLE 是 VB-Audio Software 的捐赠软件（www.vb-cable.com），不属于本程序。VB-CABLE is a donationware, all participations are welcome.
   装完后 Windows 可能把默认通信设备改成 CABLE，“开播前检查”会提示，点“改回”即可。
2. 推流软件里：麦克风只选“CABLE Output”，关闭系统声音（扬声器）采集，不要再加真实麦克风。“开播前检查”会自动核对抖音直播伴侣、B 站直播姬、虎牙直播和斗鱼直播伴侣（软件装在哪里都能识别），其他推流软件请自己确认。系统声音按推流软件上次保存的设置判断，虎牙和斗鱼要退出一次才会保存。
3. 游戏、音乐等其他声音：在推流软件里单独采集（直播伴侣用“程序音频”）。这些声音不经过本程序，混在里面的人声（如游戏内语音）也不会被消音；想让其他人的语音也被过滤，请让他们用 KOOK 等语音软件说话，并关掉游戏等程序里的语音。
4. 需要音画同步的场景请改用“中文直播消音 OBS 插件”：本程序只延迟声音（约 1.4 秒），不延迟画面。露脸时口型会对不上；游戏内语音这类混在程序声音里的人声，过滤它就得连整个程序的声音一起延迟，和画面对不上。插件在 OBS 里把画面一起延迟。
5. 双机推流（游戏电脑经采集卡把画面和声音送到另一台电脑推流）：本程序的输出只在装它的这台电脑上。麦克风和语音软件都在推流的那台电脑上时，把本程序装在那台电脑；都在游戏电脑上时请用 OBS 插件（开播方式选“直播伴侣类推流软件”，推流软件在“另一台电脑”）。详见公开仓库 docs/dual-pc。

使用
- 第一次打开时，如果“识别模型”页里“推荐”模型旁边是“下载”按钮（安装包没有带模型），点它下载（约 130 MB，从 GitHub 的 sherpa-onnx 发布页下载，下载后核对文件完整）。下载失败可以稍后再点。
- 打开程序，勾选麦克风和要过滤的语音软件（默认 KOOK），点“开始过滤”。开播前看一眼“开播前检查”，红色项要先处理。
- 过滤后的声音比画面和其他声音晚约 1.4 秒（要先听完才能判断要不要消音），观众一般察觉不到；“消音设置”里可以调。
- 关掉窗口后程序缩在右下角托盘里继续过滤；托盘图标右下角的点：绿色正在过滤，灰色没开始，红色有问题。要彻底退出，右键托盘图标选“退出”。
- 开始过滤时程序会自动启用 CABLE Input，停止或退出时禁用，免得耳机拔掉时别的声音不经过滤进入直播（“消音设置”里可以关掉这一项）。
- 屏蔽词、消音方式（静音、哔声、动物叫声等）在左侧对应页面里设置。

文件位置
- 程序：%LOCALAPPDATA%\Programs\LiveSpeechFilter
- 设置、自己加的屏蔽词、日志、下载的模型：%APPDATA%\LiveSpeechFilter。卸载程序时不删除这个文件夹，不需要时可以手动删除。

注意
- 识别不是百分之百，第一次用请先本地录一段确认效果，不要直接用于重要的正式直播。
