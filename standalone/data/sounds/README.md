# Replacement sounds

Played instead of a muted word when one of the animal sounds is chosen in 消音设置 → 替换成.
All five are CC0 1.0 (public domain dedication) from Freesound, trimmed and level-matched for
LiveSpeechFilter (48 kHz mono 16-bit). The selection is recorded in
`work/sfx-20261114/selected.json`.
