# 直播消音应用图标 · A 局部抹平

用户选择方向 A 后的交付版本。蓝色为 `#3B63FB`，深色消音块为 `#1F2329`，白色声波保留正常语音；中间深色片段里的平线表示局部静音。图标没有文字、渐变或固定状态点。

- `live-speech-filter-full.svg`：完整版矢量母版，圆角蓝色底板；画布外沿透明。用于 48px 及以上。
- `live-speech-filter-small.svg`：简化版矢量母版，透明底，无底板；四根声波柱和中间一段平线。用于 32px 及以下。
- `png/`：1024、512、256、128、64、48、32、24、20、16px 的 RGBA PNG。
- `live-speech-filter.ico`：16、20、24、32、48、64、128、256px，32 位 RGBA，内部使用 PNG 帧；适用于 Windows 11。每一帧与同尺寸 PNG 完全一致。
- `preview.png`：浅色和深色环境下的托盘 16px、开始菜单 32px、桌面 48px 及绿色状态点示意。为静态合成效果，不是 Windows 实际运行截图；按 100% 比例查看原始尺寸。
- `validation.json`：导出检查结果。

小尺寸 PNG 从简化母版逐尺寸对齐矩形边缘到整像素，不从 256px 图片缩小。小尺寸使用方端笔画增强清晰度；完整 SVG 保留圆角。16px 主笔画为 2px，中间平线为 2×1px。20/24px 的间距经整数舍入，有 1px 的光学校正差异。

状态点建议：位置限制在画布右下角约 40% × 40% 区域（x/y 均不小于 60%），外圈白色，内圈按状态变灰/绿/红；示例绿为 `#24B36B`。完整版此区域仅可能覆盖底板；简化版此区域完全透明。状态点由程序运行时叠加，ICO 和基础 PNG 不带状态点。

可直接将 ICO 用作 Windows 程序资源或安装程序图标；运行时托盘优先使用对应尺寸的 PNG，避免系统从完整版自动缩小。此交付仅提供资产，尚未接入应用、重新编译程序或生成安装包。

复现：安装 Pillow、PySide6 后，在 Windows 上运行 `python docs/design/app-icon/export_icons.py`。SVG 为渲染来源；PNG 使用 QtSvg 渲染，预览文字使用 Windows 微软雅黑字体。
