# 双机方案二：OBS 节目画面投影到采集卡

[← 返回双机推流指引](README.md)

适用：**游戏机开 OBS（装插件），直播机开直播伴侣等推流软件**，两台用采集卡连接；需要露脸、需要 OBS 场景里的元素（摄像头、文字、贴图），或者想让语音和画面对齐；也适用于游戏内语音。

> ⚠️ 这条接法还没有实测过：投影输出、HDMI 监听的声音延迟、采集卡自身的延迟都可能让音画差几十毫秒。搭好后先在直播机的推流软件里本地录一段，确认脏话处是静音的、没有原声漏出、口型和画面对得上。

## 和方案一的区别

声音部分和[方案一](voice-only.md)完全一样，区别只在画面：

| | 方案一 | 方案二 |
| --- | --- | --- |
| 画面来源 | 游戏机直接输出屏幕到采集卡 | OBS“全屏投影（节目）”投到采集卡那块屏幕 |
| 采集卡接法 | 直通、复制屏幕都可以 | 必须作为**扩展的第二块屏幕**；直通主屏的话投影会盖住游戏 |
| OBS 场景里的元素 | 没有 | 有 |
| 画面能否跟语音一起延迟 | 不能，语音晚约 2 秒 | 能（画面同步设为“总是同步”） |
| 额外开销 | 几乎没有 | OBS 要渲染投影，多占一点显卡 |

## 游戏机设置

1. 采集卡作为 **扩展的第二块屏幕** 接在游戏机显卡上（Windows 显示设置里选“扩展这些显示器”）。
2. **Windows 默认播放设备设为你的耳机**，不能是采集卡的 HDMI，否则游戏和 KOOK 的原声会绕过消音直接进采集卡。
3. OBS 场景里照常采集游戏画面（游戏采集），加上摄像头等元素。声音来源：
   - **游戏声**：游戏采集勾选“采集音频”，或给游戏 exe 单独加“应用程序音频采集”；
   - **KOOK**：“应用程序音频采集”，加“语音消音”滤镜（用游戏内语音时不需要，见下面）；
   - **麦克风**：插件自动加消音滤镜；
   - **桌面音频**：静音。
4. **工具 → 语音消音设置**：
   - 开播方式选 **OBS 直接推流**（不要选“直播伴侣类推流软件”）。
   - “其他人的语音来自”：用 KOOK 等选 **语音软件**；用游戏内语音选 **游戏或其他程序的声音里**，并按检查清单给游戏声加消音。
   - **画面同步**：想让语音和画面对齐、露脸或游戏内语音时，设为 **总是同步**（有摄像头或游戏声加了消音时，“自动”也会同步）。只过滤 KOOK 和麦克风、又不在乎语音晚 2 秒时，保持“自动”即可。
5. **OBS 设置 → 音频 → 监听设备** 选采集卡那个 HDMI 设备；要播出的来源（麦克风、KOOK、游戏声）设为 **监听并输出**，桌面音频不监听。
6. 在采集卡那块屏幕上打开 **全屏投影（节目）**：点 OBS 右下角“工作室模式”，在右侧“节目”画面上右键 → 全屏投影（节目）→ 选采集卡那块屏幕。
   - 一定要投 **节目**，不要投单个场景或来源。单个场景不经过插件的画面同步。

## 直播机设置（推流软件）

- 添加 **采集卡** 素材，打开它的音频，只用这一路声音。
- 关闭推流软件的 **系统声音** 和 **麦克风** 采集。

## 会不会标红

照上面设置，“当前场景检查”正常没有红项。和方案一一样，插件**检查不到**这些，要自己确认：Windows 默认播放设备不是采集卡的 HDMI；OBS 监听设备是采集卡；该监听的来源是“监听并输出”、桌面音频没被监听；KOOK 的输出设备；投影的是“节目”。

**没有标红 ≠ 播出去是干净的**，以本地录像为准。

## 注意

- 耳机不要接在采集卡或显示器的音频口上，否则会听到自己延迟 2 秒的回音。
- 投影窗口要一直保持全屏、不被其他窗口挡住，也不要把鼠标留在那块屏幕上。
