# 双机推流怎么设置

双机推流：一台**游戏机**玩游戏，一台**直播机**负责推流，两台之间用**采集卡**连接（游戏机的 HDMI 接到直播机的采集卡）。

> ⚠️ 本项目还没有在真实的双机环境、真实采集卡上测试过。下面的做法是按插件和程序现有的功能推出来的。**无论选哪种，搭好后都要先在推流软件里本地录一段**，确认脏话被消掉、没有原声漏出、音画对得上，再正式开播。

## 先看三样声音在哪台电脑

决定怎么设置的，是这三样声音分别从哪台电脑出来：

1. 你的**麦克风**插在哪台；
2. **队友语音**：用 KOOK、YY、Discord 等语音软件的话，它在哪台运行；还是用的游戏内语音；
3. **游戏声音**（永远在游戏机上）。

再看 OBS 和推流软件（直播伴侣等）各装在哪台。

## 选择你的情况

| 你的情况 | 用什么 | 说明 |
| --- | --- | --- |
| **游戏机开 OBS，直播机开直播伴侣推流**；队友用 KOOK 等语音软件；不露脸 | 游戏机 OBS 装插件 | [方案一：画面直出，只过滤语音](voice-only.md)（推荐，最简单） |
| **游戏机开 OBS，直播机开直播伴侣推流**；要露脸、要 OBS 场景里的元素，或想让语音和画面对齐 | 游戏机 OBS 装插件 | [方案二：OBS 节目画面投影到采集卡](program-projector.md) |
| **直播机开 OBS**，游戏机只输出 HDMI | 直播机 OBS 装插件 | 见下面的[直播机开 OBS](#直播机开-obs) |
| 麦克风和 KOOK **都在直播机**上，直播机用直播伴侣推流，不用 OBS | 直播机装直播消音（独立程序） | 见下面的[直播机用直播消音](#直播机用直播消音) |
| 队友用的是**游戏内语音** | 只能用 OBS 插件，而且游戏声要和画面一起延迟 | 方案二（画面同步设为“总是同步”），或直播机开 OBS |

**直播消音（独立程序）装在游戏机上不行**：它只能输出到游戏机本机的 VB-CABLE，直播机读不到。

**游戏机开 OBS 的两个方案，插件都选“直播伴侣类推流软件”模式，再把“推流软件在”选为“另一台电脑”**，并选采集卡的播放设备。这样插件不用虚拟摄像头和 VB-CABLE，而是把 OBS 监听设备设为采集卡、自动把要播出的来源设为“监听并输出”，还会检查 Windows 默认播放设备是不是采集卡、有没有别的程序往采集卡放声音、采集卡是否连着。

这个选项要较新的插件（设置页“开播方式”下面有“推流软件在”的版本）。旧版插件没有它，只能按方案页最后“旧版插件”一节，用“OBS 直接推流”模式手动设置，插件不检查监听相关的设置。之前照旧说明用“OBS 直接推流”的，升级后插件不会自动换模式，请自己改过来。

## 直播机开 OBS

游戏机只把画面和声音（游戏声、KOOK、走 HDMI 的麦克风）通过 HDMI 送进采集卡，不装任何东西。直播机的 OBS 装插件：

1. 采集卡用“视频采集设备”来源加进场景，并带上它的音频。
2. **工具 → 语音消音设置**，“其他人的语音来自”选 **只有我说话**（采集卡这一路由下一步单独处理）。
3. 采集卡有声音后，“当前场景检查”里会出现一条 **？ 视频采集设备…有声音，没有消音**，点 **加消音**，之后显示 ✓。游戏声、KOOK 和你的声音会作为一路一起识别。因为是视频采集设备，插件会自动让画面一起延迟，音画保持同步。
4. 麦克风如果直接插在直播机上，插件会自动给它加消音滤镜；如果麦克风走游戏机的 HDMI、直播机的 OBS 里没有麦克风来源，状态栏会提示“未找到主播麦克风音源”，在设置里关掉“自动给麦克风加消音滤镜”即可。
5. 直接推流，或者开“直播伴侣类推流软件”模式（推流软件在“这台电脑”）接到直播机上的伴侣。

好处：识别占用的几个 CPU 核在直播机上，不和游戏抢资源。代价：游戏声也经过识别，延迟和画面同步按整路处理。

## 直播机用直播消音

前提：**麦克风插在直播机上，KOOK 也在直播机上运行**，采集卡只传游戏画面和游戏声。

1. 直播机安装直播消音（含 VB-CABLE），勾选麦克风和 KOOK，开始过滤。
2. 直播伴侣：采集卡素材出游戏画面和游戏声；麦克风只选 CABLE Output；关闭系统声音采集。

代价：直播消音不延迟画面，你和队友的声音比游戏画面晚约 1.4 秒。不露脸一般能接受，露脸时口型对不上。

## 另一种传输方式：NDI

不用采集卡，也可以在游戏机 OBS 装 NDI 插件（DistroAV），直播机装 NDI Tools，经网线把 OBS 节目送到直播机。要多装软件、占用网络带宽，推流软件能不能拿到 NDI 的声音因软件而异，本项目没有测试过。
