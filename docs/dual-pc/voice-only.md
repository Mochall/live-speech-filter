# 双机方案一：画面直出，只过滤语音

[← 返回双机推流指引](README.md)

适用：**游戏机开 OBS（装插件），直播机开直播伴侣等推流软件**，两台用采集卡连接；队友用 KOOK、YY、Discord 等语音软件；不露脸。

> ⚠️ 这条接法还没有实测过。搭好后先在直播机的推流软件里本地录一段，确认三件事：脏话处是静音的；没有一份没过滤的 KOOK 或麦克风原声混进来；游戏声和画面对得上。

## 思路

- **游戏画面**照旧由游戏机直接输出到采集卡，OBS 不处理画面。
- **声音**全部交给 OBS：游戏声原样通过，麦克风和 KOOK 消音后通过，再用 OBS 的“监听”送到采集卡那一路 HDMI 的音频里。
- **你自己用耳机听原声**，实时、没有延迟。

游戏机连着采集卡的 HDMI 口，在 Windows 里会显示为一个播放设备（一般是显示器或采集卡的名字，后面带“(NVIDIA/AMD High Definition Audio)”）。往这个设备放的声音会跟着画面一起进采集卡。所以关键是：**只让 OBS 往这个设备出声，其他程序都不往这里出声。**

采集卡收到的是：游戏画面 + 游戏声（不延迟）+ 消音后的麦克风和 KOOK（约晚 2 秒）。

## 游戏机设置

1. **Windows 默认播放设备设为你的耳机**，不能是采集卡的 HDMI。这样游戏和 KOOK 的原声只进耳机。如果 KOOK 里手动选过输出设备，确认它不是采集卡的 HDMI。
2. OBS 里准备三个来源：
   - **游戏声**：游戏采集勾选“采集音频”（OBS 30 及以后），或给游戏 exe 单独加“应用程序音频采集”。**不要给它加消音。**
   - **KOOK**：“应用程序音频采集”，窗口选 KOOK，加“语音消音”滤镜。
   - **麦克风**：插件会自动加消音滤镜。
   - **桌面音频**：静音。
3. **工具 → 语音消音设置**：
   - 开播方式选 **直播伴侣类推流软件**，“推流软件在”选 **另一台电脑**，“采集卡的播放设备”选采集卡那个 HDMI 设备（列表里没有时点“刷新”）。
   - 插件会把 OBS 监听设备改成采集卡（原来的监听设备改回“OBS 直接推流”时恢复），并自动把正在播出、没静音的来源设为“监听并输出”，静音的来源不监听。不用自己去 OBS 设置里改。
   - “其他人的语音来自”选 **语音软件**。
   - 画面同步保持 **自动**。只过滤语音时，插件不会延迟游戏画面和游戏声。
   - 按 **直播机设置清单…** 核对一遍，点“我已完成”。
4. OBS 不需要点推流或录制，开着就行。

## 直播机设置（推流软件）

- 添加 **采集卡** 素材，打开它的音频，只用这一路声音。
- 关闭推流软件的 **系统声音** 和 **麦克风** 采集。

## 会不会标红

按上面设置，“当前场景检查”正常是全绿：麦克风 ✓、桌面音频已静音 ✓、语音软件已消音 ✓、游戏声音已采集（不消音）✓。只用应用程序音频采集抓游戏声、没有游戏采集时，会有一条灰色的“没有找到游戏采集或窗口采集”，只是提示。

插件会标红（状态栏和设置页）：

- Windows 默认播放或通信设备是采集卡（**最容易漏脏话的一点**，比如重装驱动、插拔设备后 Windows 自己改了）。设置页可以点“修复 Windows 默认播放设备”改回耳机或扬声器；插件不会自己改。
- 除 OBS 外还有程序正在往采集卡放声音（比如 KOOK 的输出设备选了采集卡）。只有它打开着采集卡的声音时才看得到。正在录采集卡声音的程序（比如录屏软件选了采集卡）也会被列出来；请确认列出的程序的输出设备不是采集卡，只是在录它的可以不管。
- 找不到选好的采集卡播放设备（没连好、被禁用）。
- 某个来源被设成“仅监听”（它也会进入直播）。

**检查不到的**，要自己确认：直播机上推流软件的设置、直播机自己的声音、采集卡实际有没有收到声音。所以**没有标红 ≠ 播出去是干净的**，以本地录像为准。

## 旧版插件

设置页没有“推流软件在”选项的旧版插件：开播方式选 **OBS 直接推流**（不要选“直播伴侣类推流软件”，旧版的这个模式会把监听设备强制改成 VB-CABLE）；在 **OBS 设置 → 音频 → 监听设备** 选采集卡那个 HDMI 设备；麦克风、KOOK、游戏声三个来源设为 **监听并输出**（混音器里来源的齿轮 → 高级音频属性 → 音频监听），桌面音频不监听。这种设置下插件不检查上面那些标红项，要自己确认。

## 注意

- **耳机不要接在采集卡或显示器的音频口上**：那里的声音里有你自己延迟 2 秒的麦克风，会听到回音。
- 你和队友的声音比游戏画面晚约 2 秒；游戏声绕了一次 OBS 监听，比画面晚几十毫秒，一般听不出来。
- 想让语音和画面对齐，或者要露脸，改用[方案二](program-projector.md)。
